# Features layer

One folder per route. Smart **container** pages (`*.page.ts`) compose shared UI and inject core services.

| Route | Component |
|-------|-----------|
| `/` | `home/home.page.ts` |
| `/menu` | `menu/menu.page.ts` |
| `/about` | `about/about.page.ts` |
| `/contact` | `contact/contact.page.ts` |

See [`../ARCHITECTURE.md`](../ARCHITECTURE.md).
